# Fox Sitting Upright

Made a new voxel model, a fox sitting upright with folded ears, white chest and a tail curled round the front of the base.

**Open it:** https://bean-bengal.github.io/beanbag-with-cat-in-it/

## Versions
- **v3** Made a new voxel model, a fox sitting upright with folded ears, white chest and a tail curled round the front of the base.
- **v2** Made the ears fold flat against the head, added a darker beanbag underside and lighter top, and a front paw pair.
- **v1** Built a small voxel model: green squashed beanbag with a dip, spotted cat body, round head, ears, four stubby legs and a curled tail.
